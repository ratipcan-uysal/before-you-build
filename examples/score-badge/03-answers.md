# The two questions, answered

`readiness-score` returned **CONDITIONAL** and said the document did not need shaping, it needed two answers. Both were put to Sinem the same afternoon. This is her reply, kept because a chain that only ever shows questions never shows what closing one looks like.

---

**What is the rounding rule?**

> Half up, one decimal, on the value as passed. We do not re-derive anything: if a host passes 4.25 the badge shows 4.3, and if a host passes 4.2999 it shows 4.3 as well. The seller panel has rounded this way since v2 and the disagreement is entirely in the other three surfaces.

**Does adopting the badge include moving the QA tool off the deprecated cached field, or only changing its render?**

> Moving off the field is a precondition of adoption, not a consequence. The QA tool takes the new source first and only then takes the badge. I had this in my head as obviously part of it and did not write it down, which is exactly the sort of thing you are asking about.
>
> That also fixes the success measure: zero mismatch escalations is reachable, because every adopting surface is on the new source by definition of having adopted.
